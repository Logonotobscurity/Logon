# LOG_ON OS Roadmap

## Shared kernel
Execution semantics, identity, tenancy, domain contracts, state, events, policies, permissions, evidence, audit, model gateway and observability.

## System 1 — Proof
Prospect -> Audit -> Recommendation -> Approval -> Automation -> Measurement -> Report.

## System 2 — Agent Assurance
Discover -> Threat Model -> Capability Test -> Misuse Test -> Data Review -> Permission Review -> Human Oversight -> Go-Live -> Monitoring.

## System 3 — Intelligence
Source -> Ingest -> Normalize -> Deduplicate -> Verify -> Change Detection -> Impact -> Relevance -> Opportunity -> Action.

## System 4 — Strategy
Objective -> Current State -> Gap -> Options -> Constraints -> Plan -> KPIs -> Risks.

## System 5 — Demand
Prospect -> Intelligence -> Visibility -> Outreach -> Lead -> Qualification -> Booking.

## System 6 — Delivery
Sale -> Scope -> Onboard -> Configure -> Deploy -> Test -> Launch -> Monitor -> Report.

## System 7 — Retention
Interaction -> Sentiment -> Issue Detection -> Recovery -> Review -> Referral -> Renewal.

## System 8 — Measurement
Business outcomes + system metrics + customer outcomes.

## System 9 — Learning
Trace -> Failure -> Dataset -> Evaluation -> Regression -> Improvement.

## System 10 — Board
Goals -> Intelligence -> Strategy -> Work Allocation -> Oversight -> Review.

## Specialised modules
- AI Visibility / GEO
- Reputation Intelligence
- Voice-to-Operations
- Opportunity Intelligence
- Africa Expansion Intelligence
- Market and Competitor Intelligence
- African AI research and benchmarks

## Build sequence
1. Kernel
2. Proof
3. Assurance
4. First real customer deployment
5. Intelligence
6. Demand
7. Delivery
8. Retention
9. Measurement
10. Learning
11. Strategy
12. Board/Orchestrator

## Near-term rule
Do not build the full platform before proving one complete business loop with one vertical, one workflow and one measurable outcome.
